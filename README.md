# Ecommerce-Sales-Profitability-Dashboard
# 📊 E-Commerce Sales & Profitability Analytics Dashboard

## 📌 Project Overview
This project presents an interactive, single-page Power BI dashboard designed to analyze e-commerce sales performance, revenue, profitability, product categories, customer segments, and regional sales.

The dashboard helps users identify business trends and gain meaningful insights through interactive visualizations.

## 🎯 Project Objectives
- Analyze total sales revenue and profit.
- Track monthly revenue trends.
- Identify top-performing products.
- Compare sales across product categories.
- Analyze regional sales performance.
- Understand sales channel contribution.
- Evaluate profitability and customer segments.

## 🛠️ Tools & Technologies
- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV Dataset
- GitHub

## 📈 Key Performance Indicators (KPIs)
- Total Revenue
- Total Profit
- Total Orders
- Profit Margin
- Total Quantity Sold

## 📊 Dashboard Features
- Monthly Revenue Trend Analysis
- Revenue by Product Category
- Top 10 Products by Revenue
- Revenue by Sales Channel
- Regional Sales Performance Map
- Interactive Year, Region, Category, and Customer Segment slicers
- Colorful and professional single-page dashboard design

## 📂 Dataset
The dataset contains 1,800 records and 23 columns, covering the period from 2023 to 2025.

Key fields include:
- Order Date
- Product Category
- Product Name
- Revenue
- Profit
- Quantity
- Region
- Customer Segment
- Sales Channel
- Payment Method
- Order Status

Currency: Indian Rupees (INR)

## 📁 Project Files
- `Ecommerce_Sales_Dashboard.pbix` – Power BI dashboard file
- `PowerBI_Advanced_Ecommerce_Sales_Dataset.csv` – Dataset
- `Dashboard_Screenshot.png` – Dashboard preview

## 🚀 How to Use
1. Download the repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Explore the dashboard using the interactive slicers.
4. Analyze sales and profitability trends.
